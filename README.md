# Other Half

兩人合作的小遊戲：地圖上四個圖案格配成兩對，寶藏藏在其中一格。一人只知道寶藏的顏色，一人只知道寶藏的形狀，不能說話，只能靠走位讓對方知道自己的那一半，最後兩人一人一格站滿寶藏那一對。

線上玩：https://isonaei.github.io/other-half/ （電腦鍵盤；跟電腦玩時手機也可以用畫面上的方向鍵）

- 跟電腦玩：每局隨機知道顏色或形狀，夥伴是寫死規則的 Bot。
- 兩個人玩：同一台電腦，1P 用 WASD＋空白鍵，2P 用方向鍵＋Enter；可選「同一個畫面」或「輪流看螢幕」。
